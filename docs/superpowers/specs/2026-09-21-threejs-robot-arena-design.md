# แบบออกแบบสนามหุ่นยนต์ด้วย Three.js

## วัตถุประสงค์

สร้างแผนภาพสนามสอบหุ่นยนต์แบบ 3 มิติที่เปิดใช้งานผ่านเว็บเบราว์เซอร์ รุ่นแรกจะแสดงสนามและเปิดให้ผู้ใช้ปรับแต้มลูกเต๋าที่ควบคุมทิศเริ่มต้นของหุ่นยนต์และตำแหน่งของกล่องสิ่งกีดขวางสองใบ การคำนวณเส้นทางและภาพเคลื่อนไหวของหุ่นยนต์ยังไม่รวมอยู่ในรุ่นนี้

## ข้อมูลการวัดและสมมติฐาน

- กำหนดให้สนามเป็นสี่เหลี่ยมจัตุรัสขนาด 3 × 3 เมตร ค่าที่วัดจากภาพอ้างอิงมีตั้งแต่ 121–132 นิ้ว จึงยึดขนาดสนามมาตรฐาน 3 เมตรเป็นหลัก
- ใช้หน่วยเมตรในการคำนวณภายใน โดยแปลงจากนิ้วด้วยสูตร `1 นิ้ว = 0.0254 เมตร`
- การเลื่อนหนึ่งช่องกระเบื้องมีระยะ 4.5 นิ้ว หรือ 0.1143 เมตร
- กล่องสิ่งกีดขวางทั้งสองมีขนาด 13.5 × 19 นิ้ว หรือ 0.3429 × 0.4826 เมตร
- กล่องฝั่งซ้ายวางในแนวตั้งและเลื่อนไปทางขวาเมื่อแต้มลูกเต๋าเพิ่มขึ้น
- กล่องฝั่งขวาวางในแนวนอนและเลื่อนไปทางซ้ายเมื่อแต้มลูกเต๋าเพิ่มขึ้น
- ช่องทางออกอยู่ที่ขอบสนามด้านล่างฝั่งซ้าย มีความกว้าง 39 นิ้ว หรือ 0.9906 เมตร โดยช่วงซ้ายสุดขนาด 19 นิ้ว หรือ 0.4826 เมตร จะทำเครื่องหมายเป็นช่องคะแนนพิเศษ
- เอกสารต้นฉบับไม่ได้ระบุพิกัดเริ่มต้นของกล่องทั้งสองอย่างชัดเจน จึงประมาณตำแหน่งเริ่มต้นของกล่องซ้ายให้ชิดกำแพงซ้ายที่ `(x: -1.32855, z: -0.25)` และกล่องขวาให้ชิดกำแพงขวาที่ `(x: 1.2587, z: 0.35)` พิกัดเหล่านี้จะเก็บไว้ในส่วนตั้งค่ากลาง เพื่อให้แก้ไขภายหลังได้โดยไม่ต้องเปลี่ยนระบบแสดงผล
- วางหุ่นยนต์ใกล้มุมบนขวาที่ `(x: 1.15, z: -1.15)` ทิศตั้งต้นที่กำหนดไว้คือหันขึ้นด้านบนของแผนภาพ หรือแกน `-Z` หากลูกเต๋ากำหนดทิศได้แต้ม `n` หุ่นยนต์จะหมุนตามเข็มนาฬิกา `n × 90°` เมื่อมองจากด้านบน
- ตัวเลือกแต้มลูกเต๋ามีค่าตั้งแต่ 1–6 กล่องแต่ละใบจะเลื่อนจากจุดเริ่มต้นเป็นระยะ `แต้มลูกเต๋า × 4.5 นิ้ว`

## รูปแบบการส่งมอบ

สร้างเป็นหน้าเว็บขนาดเล็กภายในโฟลเดอร์โปรเจกต์ โดยใช้ HTML, CSS และ JavaScript Modules โหลด Three.js รุ่นที่กำหนดตายตัวและ OrbitControls ผ่าน CDN เพื่อให้รุ่นแรกเปิดใช้งานผ่านเว็บเซิร์ฟเวอร์ภายในเครื่องได้โดยไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

ไฟล์ที่วางแผนจะสร้าง:

- `index.html` — โครงสร้างหน้าเว็บและส่วนควบคุมที่รองรับการเข้าถึง
- `styles.css` — รูปแบบหน้าจอที่ปรับตามขนาดอุปกรณ์
- `arena.js` — การสร้างฉาก การตั้งค่าสนาม การประมวลผลแต้มลูกเต๋า การควบคุมกล้อง และการแสดงผล
- `README.md` — วิธีเปิดใช้งานภายในเครื่องและรายการสมมติฐานเกี่ยวกับระยะต่าง ๆ

## การออกแบบฉาก

ฉาก Three.js ประกอบด้วย:

- พื้นสนามสี่เหลี่ยมขนาด 3 เมตร พร้อมเส้นกระเบื้องขนาดช่องละ 4.5 นิ้ว
- กำแพงเตี้ยรอบสนาม โดยเว้นช่องทางออกที่มุมล่างซ้าย
- เครื่องหมายบนพื้นเพื่อแสดงช่องทางออกทั้งหมดและช่วงคะแนนพิเศษ
- ตัวหุ่นยนต์แบบเรียบง่ายบริเวณจุดเริ่มต้นมุมบนขวา พร้อมลูกศรบอกด้านหน้า
- กล่องสิ่งกีดขวางสองใบในแนวการวางที่กำหนด
- ป้ายกำกับแบบกระชับสำหรับจุดเริ่มต้น ทางออก ช่องคะแนนพิเศษ กล่องซ้าย และกล่องขวา
- แสงโดยรอบและแสงแบบมีทิศทาง พร้อมเงาแบบนุ่มเมื่อเว็บเบราว์เซอร์รองรับ

มุมกล้องเริ่มต้นเป็นมุมเอียงที่ทำให้มองเห็นความลึกและเห็นสนามทั้งหมด ผู้ใช้สามารถใช้ OrbitControls เพื่อหมุน ซูม และเลื่อนกล้องได้ ปุ่ม “มุมมองด้านบน” จะเปลี่ยนเป็นมุมมองจากด้านบน ส่วนปุ่ม “รีเซ็ตมุมมอง” จะกลับไปยังมุมเอียงเริ่มต้น

## ส่วนควบคุมและสถานะ

หน้าเว็บมีช่องเลือกแต้มลูกเต๋าสามช่อง:

1. แต้มสำหรับกำหนดทิศเริ่มต้นของหุ่นยนต์ ตั้งแต่ 1–6
2. แต้มสำหรับกำหนดตำแหน่งกล่องซ้าย ตั้งแต่ 1–6
3. แต้มสำหรับกำหนดตำแหน่งกล่องขวา ตั้งแต่ 1–6

เมื่อเปลี่ยนแต้ม วัตถุที่เกี่ยวข้องจะปรับตำแหน่งหรือทิศทางทันที พร้อมปรับข้อความสถานะที่บอกทิศสุดท้ายและระยะเลื่อนของกล่อง ปุ่ม “สุ่มแต้ม” จะสุ่มค่าทั้งสามสำหรับใช้ฝึกซ้อม สถานะทั้งหมดอยู่ภายในหน้าเว็บ ไม่มีการส่งข้อมูลผ่านเครือข่ายหรือบันทึกลงพื้นที่จัดเก็บ

ช่องเลือกและปุ่มต่าง ๆ สามารถใช้งานด้วยแป้นพิมพ์ พื้นที่แสดงผล 3 มิติจะมีคำอธิบายสำหรับเทคโนโลยีช่วยการเข้าถึง และข้อความที่เปลี่ยนแปลงจะประกาศผ่านบริเวณ `aria-live`

## การไหลของข้อมูลและการแบ่งส่วนระบบ

ไฟล์ `arena.js` จะแยกข้อมูลการวัดและค่าตั้งต้นออกจากการทำงานของฉาก:

- ฟังก์ชันแปลงหน่วยจากนิ้วเป็นเมตร
- ส่วนตั้งค่าสนามเก็บขนาด พิกัดเริ่มต้น และทิศทางการเคลื่อนที่
- ชุดฟังก์ชันสร้างพื้น กำแพง หุ่นยนต์ กล่อง ป้าย แสง และกล้อง
- ฟังก์ชันปรับสถานะหนึ่งจุด ทำหน้าที่ตรวจสอบแต้ม คำนวณการแปลงตำแหน่ง และปรับวัตถุพร้อมข้อความสถานะ
- ฟังก์ชันช่วยควบคุมกล้องสำหรับเรียกคืนมุมมองที่กำหนดไว้สองแบบ

การคำนวณตำแหน่งทั้งหมดใช้ระบบพิกัดสนามเดียวกัน โดยจุดกึ่งกลางพื้นสนามคือ `(0, 0, 0)` แกน X บวกชี้ไปทางขวา และแกน Z ลบชี้ไปทางด้านบนของแผนภาพ การกำหนดนี้ช่วยให้สามารถเพิ่มระบบวางแผนเส้นทางในอนาคตได้โดยไม่ผูกติดกับทิศทางการแสดงผล

## การจัดการข้อผิดพลาด

- ปฏิเสธหรือจำกัดแต้มลูกเต๋าที่อยู่นอกช่วง 1–6 ก่อนนำไปคำนวณ
- แสดงข้อความที่เข้าใจง่ายหากไม่สามารถเริ่มต้น WebGL ได้
- กำหนดรุ่นของไฟล์ที่โหลดจาก CDN ให้แน่นอน และแสดงข้อความแจ้งหากไม่สามารถโหลด Three.js ได้
- จำกัดพิกัดตั้งต้นและระยะเลื่อนสูงสุด เพื่อไม่ให้กล่องเคลื่อนออกนอกสนาม

## การตรวจสอบ

เปิดหน้าเว็บผ่านเว็บเซิร์ฟเวอร์ภายในเครื่องและตรวจสอบว่า:

- มองเห็นสนามครบทั้งในมุมเอียงและมุมมองจากด้านบน
- แต้มลูกเต๋าทุกค่าตั้งแต่ 1–6 ทำให้หุ่นยนต์หมุนครั้งละ 90 องศา หรือทำให้กล่องเลื่อนครั้งละ 4.5 นิ้วอย่างถูกต้อง
- กล่องซ้ายเคลื่อนไปทางขวาเท่านั้น และกล่องขวาเคลื่อนไปทางซ้ายเท่านั้น
- ความกว้างช่องทางออกและช่วงคะแนนพิเศษตรงกับค่าที่กำหนด
- การควบคุมกล้องและปุ่มเรียกคืนมุมมองทำงานได้
- ส่วนควบคุมใช้งานได้ทั้งหน้าจอเดสก์ท็อปและหน้าจอแคบ
- ไม่มีข้อผิดพลาดขณะทำงานในคอนโซลของเว็บเบราว์เซอร์

## ส่วนที่รองรับการพัฒนาในอนาคต

ส่วนตั้งค่าและระบบพิกัดจะเตรียมไว้ให้เพิ่มขนาดจริงของหุ่นยนต์ ระยะเผื่อการชน การคำนวณเส้นทาง และภาพเคลื่อนไหวของหุ่นยนต์ในรุ่นต่อไปได้โดยไม่ต้องสร้างฉากสนามขึ้นใหม่
